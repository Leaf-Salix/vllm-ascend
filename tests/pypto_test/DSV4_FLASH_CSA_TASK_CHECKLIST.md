## 1. 最终交付与验收合同

### 1.1 目标

1. 正式 W8A8 模型的 PTO 接入功能正确，支持当前声明的 decode、padding 和 ACL Graph 场景。
2. 保留精度版、性能版两个入口；共用适配及数值中性实现，明确隔离算术差异。
3. 精度版尽力对齐 Native 的规约规则、量化顺序和舍入；不把完全 bit 一致作为无条件目标。
4. 性能版允许采用 pypto-lib 或 Native 上游已有的精度策略，先看性能收益；
   保留方案仍须独立通过逐元素、状态和整模型验收。
5. 最终 PTO 整模型表现必须明确优于 Native，且性能版
   **HC_pre → norm → CSA → HC_post 完整设备区间 <750 μs**。
   原单卡泳道 ≤725 μs 仅为优化参考，不再作为最终验收线。
6. 四张目标权重 `wq_a / wq_b / wo_a / wo_b` 的 NZ 都继续推进；
   编译限制须先在算子侧寻找解法，未实现不能写成完成。
7. mode=1、mode=2 均评估后选定性能更好的主口径；ND 独立实现与回归入口长期保留。
8. 性能版保留一套当前实现，长短上下文、batch及工作量策略在PTO算子内部按实际输入选择，
   不按测试档位切换历史源码版本。阶段对比使用同一套算子源码的实测结果；
   旧版数据可以用于优化过程对照，不能仅凭计算分支未变就代替当前版本实测。

**当前执行优先级（2026-09-27 用户最新调整）**：只针对PTO改造vllm-ascend，最小粒度，不改Native流程。
PTO内直接读写Native物理页及长档调度保护已保留，使用N128加载交错QK/WS；补当前同源码七档并继续降低分页读取成本。

### 1.2 功能错误与精度权衡分别处理

| 类型 | 判据与处理 |
| --- | --- |
| 功能错误 | 错误布局/stride/offset、越界、漏写、错误 metadata、陈旧状态、未声明回退、非有限值、错误同步均必须修复，不得靠容差掩盖 |
| 精度版算术 | 对齐 Native 规约、量化顺序及舍入；逐元素报告差异，区分固定实现差异与运行间波动 |
| 性能版算术 | 可以采用 pypto-lib 或 Native 上游策略；逐项注明与精度版的差异、适用范围和误差证据 |
| 整模型 | 必须逐 token 一致，同时检查真实 DSpark 草稿数、接受数/长度及层级误差 |
| metadata 与保护区 | 长度、页号、slot、掩码等整数/索引逐元素精确一致；不得写的区域保持不变 |
| 浮点 cache/state | 每种状态单独明确有效范围、atol/rtol、误差统计及参考来源，未定标准不能 PASS |
| 量化 INT8 / Top-K | 允许符合明确量化/选择/tie 规则的差异，前提是逐元素误差受控、逐 token 和 DSpark 统计一致；规则须在验收前明确，不把它们与 metadata 索引混为一类 |
| 非确定性 | 先量同输入重复执行的逐元素误差，再比较实现之间的误差；不能以 mean/absmax 相同替代数值验收 |

现有 BF16 `atol=1e-2, rtol=1e-2` 仅是旧单层输出标准的参考，
不得直接套用 mHC 残差流、所有中间量或全部浮点状态。
门槛须先与对象和算法对应，再用于新实验；失败后不得自动放宽。
