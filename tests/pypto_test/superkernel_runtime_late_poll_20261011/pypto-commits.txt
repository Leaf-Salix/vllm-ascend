    试验(PyPTO): 为局部任务边界预留资源并生成后到通知入口

    保持算子侧局部 wait_pre_task_end/set_next_task_start 写法，不增加整 task 作者属性或自动前缀识别。统一在 MemoryReuse 与内存分配阶段为 Set 后的完成通知预留 64 字节 scratch，放在显式跨核 FIFO 之后；地址作为编译器内部属性传给代码生成，并要求 PTOAS 为通知预留同步事件。

    编译器生成独立尾部处理入口，通过参数指针值 2 进入，跳过算子主体及前驱状态初始化。只有原运行时首次交接探测未命中时才调用，发出有序 DMA 通知并观察既有 DMB 派发；真实完成与 FIN/ACK 继续归运行时管理。通知区由配套 TMR SDK 在共享 HBM 管理。

    配套 Simpler 钉到 1c258b041，保留旧单次探测对照。内存分配原 22 项及新增 2 项回归通过；单卡 AIC/AIV 两种计算长度、两组输入、输出及保护区、图重放通过，并捕获原首次探测之后的后到交接；MIX 两项真机回归通过。128K/B16 无插桩 CSA 对照独立记录，不用小例子替代性能结论。
