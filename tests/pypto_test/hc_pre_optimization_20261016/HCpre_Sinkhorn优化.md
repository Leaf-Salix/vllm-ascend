**当前按档位保留有收益的改动：T33～95 仅索引优化，T97～144 仅广播加法，T>144 两项组合；T1～32 和 T96 保持原版。** 本说明保留 Sinkhorn 专项对照；本次 PR 相对 SE1012 的两项合并收益另见[合并性能报告](HCpre_两项优化性能.md)。

## 1. 两项改动分别解决什么

### 1.1 整数索引：去掉不必要的浮点运算

Sinkhorn 需要每行、每列的和。矩阵展平后，用 `gather` 取伙伴数据，再两两相加即可得到四项之和。原版普通布局分支用浮点乘法、取整和类型转换寻找伙伴，实际上只需翻转位置编号的一位：

| 伙伴关系 | 例子 | 等价索引 |
|---|---|---|
| 相邻两列 | 0↔1，2↔3 | `ids ^ 1` |
| 间隔两列 | 0↔2，1↔3 | `ids ^ 2` |
| 相邻两行 | 0↔4，1↔5 | `ids ^ 4` |
| 间隔两行 | 0↔8，1↔9 | `ids ^ 8` |

这里生成的是位置，不是修改矩阵数值。例如第一行 `[a,b,c,d]`，先按 `^1` 取伙伴相加，得到 `[a+b,a+b,c+d,c+d]`；再按 `^2` 取这一步的结果相加，每个位置就都有 `a+b+c+d`。列和同理。只翻转低四位，不跨 token。

实际接口使用 INT16 XOR，因此先将 INT32 索引和掩码按位视作成对 INT16，异或后再视回 INT32；不做浮点数值转换。减少的是索引生成指令，后续 gather 和归一化逻辑不变。

**T96 原本已使用整数索引及另一种排列方式，本次保留它的原实现。** 数学等价不代表所有档位都会更快，最终范围由真机对照决定。

### 1.2 广播加法：省去显式扩展偏置

```python
# 原版：先把 [1,16] 偏置扩展到 scaled 的行数，再相加。
logits = pl.add(scaled, pl.col_expand(raw, base))

# 候选：直接让每一行加同一组偏置。
logits = pl.col_expand_add(scaled, base)
```

数学不变。在最初 T168 仿真中，这种表达还避开了生成代码的 UB 部分重叠；它是算子侧绕开，不是修复 PyPTO 内存规划或模拟器。它自身是否有性能收益，必须与索引优化分开测。

## 2. 最终按哪些档位保留

| 已有档位 | 保留的改动 | 选择依据 | 最后复测的汇总收益 |
|---|---|---|---:|
| T1～32 | 保持原版 | T16/T32 明显获益，但 T8 两组回退；不新增单点分支 | 不计收益 |
| T33～48 | 仅整数索引 | 两组同向，叠加广播反而削弱收益 | 4.64%～5.13% |
| T49～95 | 仅整数索引 | 与组合版接近，广播没有明确额外收益，保留更少改动 | 1.19%～5.48% |
| T96 | 保持原版 | 已有整数索引，广播未见收益 | 不计收益 |
| T97～144 | 仅广播加法 | 仅索引的汇总耗时变慢，仅广播更好 | 2.21%～5.58% |
| T>144 | 两项组合 | 索引本身有效，组合多数点更好，并沿用有效仿真写法 | 已测到 T500：3.08%～5.80% |

这些选择通过已有分档常量在编译时确定，不增加按单个 T 特判的运行时分支。筛选候选的六个生成函数与各自选中的已测版本一致；小档与 T96 的生成计算代码和原版一致。

**收益指汇总中位数，不是每个进程都更快。** 最后一轮中，T95 有一对回退 1.02%；T112/T128/T144 有一对分别回退 2.21%/0.98%/0.69%。未改代码的 T32 也出现 2.24% 的汇总差异，说明存在运行波动，但尚不能把每次回退的原因都定为已解释的噪声。T97～144 收益较弱，仍需目标环境复验。

## 6. 原版仿真异常的关键结论

原版 T168 的 `logits = scaled + bias` 中，两个 8×16 FP32 临时量各占 512 B：scaled 起始地址 33408，logits 起始地址 33664。输出前半段与输入后半段重叠 256 B，前一次写回可能覆盖后一次尚未读取的输入。

保留三个定位事实：

1. 同一个 kernel 二进制，真机三个输出通过，独立仿真的 comb 失败；mixed/post 通过。
2. 只把 scaled 移到不重叠地址，仿真全部通过；错误中间值符合前四行输出覆盖后四行输入的关系。
3. 重叠地址在 PyPTO 输出的 `.pto` 中已经存在。生命周期规则允许输入最后使用与输出生成在同一语句交接，但允许完全原地计算不等于允许任意错位重叠。

因此优先定位范围是 **PyPTO 内存规划及原地访问约束**，不能仅因真机通过就认定为模拟器缺陷。尚未细分到具体分配步骤或约束声明，也未证明真机通过所依赖的内部读写时序。SE1012 归档的大档生成代码已有相同问题，不是后来 RMS 复用引入。

广播加法使本轮 T168 生成地址不再重叠，从而得到有效仿真参照；没有硬编码地址或修改编译器。关键实验与二进制指纹（本地归档） · 错误中间值（本地归档）
