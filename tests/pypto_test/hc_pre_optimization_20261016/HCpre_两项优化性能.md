# HC_pre 两项优化：RMS 输入复用与分档 Sinkhorn

本次相对目标分支 SE1012（`f04320413`）合并两个小改动：T33～48 复用投影输入计算 RMS；按已有档位简化 Sinkhorn 索引或使用广播加法。算子接口、数学公式、输入输出类型和 20 轮 Sinkhorn 不变，没有叠加此前全档位 DB 候选。

**本次同批次三版复测中，合并版在 19 个改动测试点的汇总耗时均下降，幅度 0.45%～6.75%；单组和单进程仍有波动。仅 RMS 版在 T33/T40 汇总获益，在 T48 略慢，不能用本表宣称它在所有输入上独立稳定获益。**

## 1. 两项优化改了什么

### RMS 复用：T33～48 去掉重复搬入与转换

原版每个 K1024 任务先读取整块输入、转换为 FP32 供投影；随后为 RMS 再读取和转换两个 K512 半块。现在每个半块只读、转一次，同时服务投影与 RMS。

```text
原版：读 K1024 → 转换 → 投影
      再读前 K512 → 转换 → 平方和
      再读后 K512 → 转换 → 平方和

优化：读前 K512 → 转换 ┬→ 投影
                      └→ 平方和
      读后 K512 → 转换 ┬→ 投影累加
                      └→ 平方和累加
```

该档采用普通循环，保留原跨核双槽；没有新增外层 pipeline。写回前恢复投影的 32 列有效形状，以匹配 GM 布局，数学输出仍是 24 个系数。

T48 仿真在 core0.vec1 可看到输入加载由三次变为两次，单段逻辑读取由 96 KiB 降到 48 KiB；重复转换同时消失。全核总 tick 为 **38409→36922，下降 3.87%**，两版输出逐字节一致并通过 CPU 参考检查。[前后 core0 流水](evidence/rms/core0_before_after.json)只保留 baseline/k512_range 两版，事件时间未改；统计（本地归档）。

### Sinkhorn：只在实测有收益的已有档位使用

普通布局的伙伴索引可直接用 `ids ^ 1/2/4/8` 替代浮点乘法、取整和转换；偏置可直接广播相加，省去显式扩展。两项改动分开对照后保留如下范围：

| T 范围 | RMS 复用改动 | Sinkhorn 改动 |
|---|---|---|
| 1～32 | 不改 | 不改；T8 未受益，不为单点新增分支 |
| 33～48 | K512 普通循环复用输入 | 仅整数索引 |
| 49～95 | 不改 | 仅整数索引 |
| 96 | 不改 | 不改；原版已有整数索引 |
| 97～144 | 不改 | 仅广播加法 |
| >144 | 不改 | 整数索引＋广播加法 |

T168 的有效仿真参照为“仅广播→广播＋索引”，总 tick **60871→56461，下降 7.24%**；索引区域由 49 条浮点相关指令变为 20 条整数逻辑及掩码指令。不能把它写成 SE1012 原版的有效前后仿真，也不能将总 tick 的全部下降都归因于一个局部区域。详见 [Sinkhorn 优化说明](HCpre_Sinkhorn优化.md)。新推广档位本轮没有新增核内仿真。

## 3. 怎么测、验证到哪里

| 项目 | 本次条件 |
|---|---|
| 输入 | `[T,4,4096]` BF16，权重/scale/base FP32；三个版本共用相同输入与参考输出 |
| T | 表中 24 个边界/代表点，覆盖六档至 T500；不是逐个遍历全部 500 个 T |
| 调用与计时 | 普通调用、无 replay；DFX 完整算子设备跨度，每窗口最多 3 次 |
| 每进程 | 准备 5 次、预热 5 次、正式 20 次 |
| 顺序 | A/B/C/C/B/A，再 B/C/A/A/C/B；A 原版、B 仅 RMS、C 合并 |
| 精度 | 三输出对 CPU 参考；mixed 使用 atol/rtol=0.01/0.01，post/comb 使用 1e-5/1e-4；检查输出两端保护行 |
| 结果 | 12 个进程×24 个 T，共 288 次场景精度及保护检查全部通过 |
| 环境 | a2a3 平台，CANN 9.3.0；PyPTO `00d5ab9`，Simpler `17e3424`；本地 ABI 适配状态见环境记录 |
