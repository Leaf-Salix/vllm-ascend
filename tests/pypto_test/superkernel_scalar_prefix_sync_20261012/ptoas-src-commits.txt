    修复(PTOAS): 禁止自动事件初始化越过局部任务等待边界

    Scalar 前缀含 if/loop 时，原 SyncIR 将其视作首个流水节点，事件分配遂把跨迭代初始 Set 放到 wait_pre_task_end 之前；真实 CSA 的 Q 反量化已触发这一问题，可能触碰仍在执行的前驱事件。

    在已校验、无条件的任务 Wait 处重启流水同步分析的节点序列，保留此前收集的分配与视图别名以及原 Scalar IR。既不移动安全前缀，也不改变无边界算子、手工事件、运行时派发和 ACK 语义。

    新增含 Scalar if、循环和前缀描述符的回归：旧编译器因 Wait 前 Set 而失败，新编译器通过；连同局部 Wait、MIX、显式事件及不安全前缀拒绝共 7 项检查通过。完整单卡 CSA 验证单独记录。
