# 无后继短任务：去掉 Wait 的控制字段读取，开销仍未清零

接续过程 044。只使用私有 TMR、CANN 9.2、单卡 0；没有新测 CSA/HBG/整模型，
公共安装与算子没有切换。保持原 dispatch、选核、ACK 流程及用户的 early-resolve 设置。

## 两个内部传参候选

1. Simpler `946011175`：给支持局部 Wait 的物理入口增加第二个 Scalar 参数，
   直接传递 executor 已知的交接状态。它去掉 Wait 的 GM 标志读取，但执行器需要判断入口 ABI。
2. Simpler `66d6ce63e`：恢复原有单指针物理入口；只在实际交接的原有 ACK 分支中，
   用已对齐 args 指针的低位传递状态。编译器先清除该位再访问 args，并把状态传给内部 Wait。
   普通执行器路径不做 ABI 查询；被标记的 kernel 入口仍有解码与条件判断。

两版都不改变算子作者写法；局部 Wait/Set 保留。只有真实交接进入完成回调，
无后继仍由 executor 做原 PIPE_ALL 等待。新路径不再写回 LocalContext 的热行标志，
旧 demo 接口继续兼容。PTOAS 只改局部 Wait 的参数转发，Scalar 前缀保留机制未变。

`marked_memory_wait` 是同 SDK 的旧热行读取诊断控制，只能用于本无后继图，
不能作为真实交接实现。它同时包含当前 wrapper 的参数处理，因此不是旧版本完整运行时的基线。

## 单核窗口结果

`spmd(1)`，一个 32×256 FP32 load/add/store task，没有后继。每版交错 30 次；
两次采集都完整取得 90/90 条记录。单位 μs，窗口包含 kernel 与 executor 排空。

| 实验 | 路径 | min | mean | max |
| --- | --- | ---: | ---: | ---: |
| 第二物理参数 | 普通 | 1.380 | 1.534 | 2.200 |
| 第二物理参数 | 热行控制 | 1.520 | 1.807 | 2.460 |
| 第二物理参数 | 寄存器状态 | 1.540 | 1.711 | 2.340 |
| 指针交接位 | 普通 | 1.360 | 1.539 | 2.180 |
| 指针交接位 | 热行控制 | 1.500 | 1.713 | 2.520 |
| 指针交接位 | 寄存器状态 | 1.400 | 1.605 | 2.460 |

最新候选相对同轮热行控制少 0.107 μs，但仍比普通多 0.067 μs，不能报零开销。
不要跨轮直接相减作为收益。profiling 会禁用实际交接探测；该窗口不能证明非 profiling 尾部探测零成本。
本轮只证实减少控制字段读取有帮助，没有把余量武断归给函数调用、寄存器保存或 Scalar-bound。

## 功能、版本与证据

- 两版各通过 3 项设备基础功能检查，包含输出/保护区与真实同核交接；最新 CPU 调度器 9 项、
  定向 early-resolve codegen 1 项、离线设备用例编译 3 项通过。
- 第二参数版 AIV 两轮重叠 48/48、48/48，AIC 11/24、24/24；
  指针交接位版 AIV 16/48、48/48，AIC 15/24、24/24。
  此处完成时刻涵盖本核全部流水，不是纯 Vector/Cube 完成；不能当作 CSA 交接率。
- 任务分别为 `task_20261011_142723_416298025094`、
  `task_20261011_145252_116220028054`，均退出 0、释放卡。
- 最新候选 PyPTO `320beb494`、PTOAS `4a5ce22a`、Simpler `66d6ce63e`。
  PyPTO 修改基于 `4a23fb1e9`，PTOAS 基于 `d53e3af3`；补丁与生成的三版短任务 C++ 均在本目录。
  `register_stage_pypto.patch` 保存被第二版替代的 PyPTO 中间状态。
- `*_single_profile.json` + `*_single_events.json` 可按 run_boundaries 对齐重算核内时间；
  `*_48_events.json` 保存完整 Event 样本；`analysis.json` 是汇总；`*_task.log`、
  `*_functional.xml`、`*_{aiv,aic}_trace.json` 保存任务与功能证据。

用户指出迭代过慢后，本轮不再扩大测试或追加小变体。当前保留为私有功能候选，目标未完成。
后续优先审查能否让编译器生成独立普通入口，使无交接路径不携带 Wait 的状态判断与回调分支；
双入口的代码体积、注册成本和完成语义仍需审查，不把尚未实现的方案写成结论。
