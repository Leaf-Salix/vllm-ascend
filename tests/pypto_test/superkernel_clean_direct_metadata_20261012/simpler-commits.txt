    试验(TMR): 随原始任务下发直接通知资源并保持控制缓存行只读

    新增 RuntimeDirectPollClean 协议：在原有 TaskPayload 的四字节对齐空隙中编码 AIC/AIV 的 64B scratch 地址，由原派发路径填入 GlobalContext，局部 Set 不再写回资源或协议号，普通完整收尾不再刷新未修改的控制缓存行。

    直接路径仍要求当前 MIX 成员同时具有 tail 与 callback 编译契约；非默认事件的 kernel 继续走编译回调，不修改 early_resolve、排队位置、ACK 触发或后继选择。按真实 worker 类型调用既有强符号通知函数，诊断模式仍完整串行回退。

    验证：CPU 调度执行输入测试 14 项通过，覆盖 AIC/AIV 成员隔离、零地址编码、范围和对齐拒绝、双缓冲复用清零，固定 payload 布局断言通过。单卡功能及 128K/B16 同 SDK 性能对照另行记录；当前未作为默认优化启用。
