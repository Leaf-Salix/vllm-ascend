## 补充分组口径

同核相邻交接不是全部提前执行机会。已有trace还显示：短档有166/768个后继在前一整组的
最后尾部记录之前开始，长档为768/768；其中包含空闲核等待其他核生产者的提前前缀。
短档各组48个task的开始时间跨度为8.06～20.86μs，明显大于标定的约5μs单task窗口。
这支持继续检查派发准备成本，但不能把跨度完全归因于AICPU，或将166/768外推成未插桩比例。
start→return还包含后继Wait等待，不能将它直接称为Scalar计算时间或据此判为Scalar-bound。
