# 固定K的KV投影：扩大L1 K块

基底30f2b228，独立工作树`.cache/csa-kv-k512-30f2b228`。只把性能版atomic0的KV_K_TILE 256→512。
M/N分组、每输出完整4096列单累加链、RMS/RoPE/存储接口均不变，atomic1及精度版不改。
CPU代码生成须核对L0分块；数学上的K遍历不变不等于浮点逐bit不变，以逐元素设备证据判断。

依据：当前固定K每个输出块需16轮L1流水；上游pypto-lib的split-K4每块只遍历局部K。
不恢复atomic，尝试把单块流水次数降到8；Native当前KV投影仍明显短于PTO。
扩大tile可能增加L1压力并改变Cube分块，不预设收益；不与EP16入场诊断混合。
