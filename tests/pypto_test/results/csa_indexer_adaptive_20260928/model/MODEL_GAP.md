GMM 是两类专家矩阵乘任务 duration 总和，可能与其他任务重叠，不能直接加到 FFN critical span。FFN 还含分发、回收及跨 rank 到达等待。

## 已证实与未证实

- 七档 CSA 区间都降低，但专家 GMM duration 均增加约1.01～1.68ms。FFN增加或首层等待会抵消部分收益。
- 128K/B8 正式 forward 慢4.77%，独立 profile 主图反而快4.05%。完整主流图首尾也只有约307/268μs位于HC区间之外，无法用漏算首尾解释两轮胜负反转。
- 8K/B16 最终 token 相同，但 rank8/12 各少接受一个草稿，正式末步请求位置不同。本档整体验收失败；该行 trace 仅作诊断，不是有效整模型加速成绩。
- 历史同请求路由诊断曾发现PTO专家选择更分散，但本版尚未直接采集路由，不能把本表GMM增量唯一归因为atomic或某个舍入点。
- 下一步先对齐同轮forward事件与完整图，分清图外等待和独立轮状态；然后针对短档DSpark及下游路由检查有依据的数值边界。
