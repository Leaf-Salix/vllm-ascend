## 旧结论与长尾的关系

[长档定向100次复测](../csa_cache_tail_guard_20260927/README.md)只改变Score准入/提前释放：
128K/B16单层PTO的均值1350.31→1263.05μs，P50 1253.67→1262.43，P95 1607.34→1280.96。
均值下降且P50略升，支持此次收益主要来自压低尾部；不是核内正常样本加速。
该对照是单卡单层，不能直接给旧16卡整模型差距分摊百分比。

旧六档报告中，128K/B16的CSA P50为Native1291.83/PTO1840.58μs，PTO P95为2335.63μs。
当时中位数和尾部都偏慢，不只是少数极端样本推高均值；EP16也可能把不同层的慢rank扩散到多数forward。
旧源码还包含不同cache与核内路径，本轮相对旧报告的改善不能全部记作sync_start收益。
特别是8K没有启用此次长档整组准入策略，短档改善须与之前cache/核内优化一起解释。
当前报告同时列均值、P95/max和每步最慢rank均值，保留所有样本；10步观测不用于证明罕见长尾永不出现。
