# 核内恢复第1项：保留Native式PV N128/K128与交替累加缓冲

调度五轮已结束，基底07365e52，仅改性能版Sparse的PV计算；24个MIX任务、QK、五块softmax、
BF16量化时机、跨query流水、事件协议及跨任务调度都不变，精度版不变。
当前pypto-lib2164563也用pl.matmul(P,V)；本地生成代码为N512/K32，沿K四次MMA并累计。
Native arch32/sparse_attn_sharedkv_scfa_block_cube.h的PV使用N128/K128及交替L0C。
本次将P搬到L0A驻留，每个N128输出使用完整K128，并交错下一块Cube与上一块FIX写出。
生成代码确认N128/K128，两个存活累加tile；不改成旧试验的联合softmax/跨五块PV累计。
MMA分块表达改变，不承诺FP32累加结果逐bit一致；必要数值诊断如下。
