# 保留：Indexer长历史1024候选块，短历史768

基底ec12e0e9。在同一性能版算子中，按实际`kv_seq_lens / 4`的最大值选择：
超过8192压缩候选使用1024候选/轮，其余Native-Cube路径保留768。选择由设备输入决定，不按测试脚本换版本。
同一个`indexer_score_topk_native_cube`用constexpr参数表达两种分块；每种仍24MIX任务，依赖和预派发开关不变。

Native QLI的S2基本块是2048，本候选吸收较大块减少循环和跨核通知的做法，仍保持双query、N128 QK panel和FP16/Cube规约。
完整8192 leaf的每AIV半区为4096候选：384一轮的11轮改为512一轮的8轮；
每leaf的Cube候选计算由8448降到8192，同时减少3次Score准备/消费循环。
最新pypto-lib2164563使用768候选的缓冲Score路径且有不同的head规约，不能直接用历史727.98μs图算同输入加速比。
当前仍有独立系数准备、GM缩放分数和Top-K合并，与Native完整融合/流式Top-K不同；UB驻留候选已独立撤回，未叠加。
