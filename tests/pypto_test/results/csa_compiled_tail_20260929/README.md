# 实际编译入口的长档 P95 定位

同配置首轮 128K/B16 PTO 的20次计时中，3次达到1249.74、1391.56、1455.72μs，
其余约1027–1053μs。Native同卡P95为1223.50μs，因此不能仅凭PTO均值更快接受稳定性。

本轮只补受影响的128K/B16，不扩跑矩阵。复用已通过的生产编译入口和冻结d8627207，
先保留20次无profiler计时及状态检查；再独立采20次有编号的图重放profile，
按调用顺序对应图外事件、aicore根kernel和AICPU执行区间。
据此区分根内变慢与图派发前后空隙；profile数据不混入正式均值。
不预设由dummy、sync_start或共享机干扰导致，也不把一次不再复现当成长尾已修复。
