# KV按行数选择M32/M64，并保持固定K规约

基底f1e4cee2，独立工作树`.cache/csa-kv-adaptive-f1e4cee2`，包含已验证免seed。
原M32先导两档核内已缩短约52%～54%，当前将其整合成同一源码内部的选择策略：

- atomic0且当前tile行数<128：M32、按完整M32块数启用最多3个M组。
- atomic0且行数≥128：M64、按完整M64块数启用最多3个M组，避免大batch的额外权重读取轮数。
- atomic1：原M64及每组至少两个M64块的规则保持。

共用一个constexpr投影函数，DENSE_M和GROUP_ROWS在编译时展开；运行时根据实际行数选分支。
每个输出仍由唯一M/N块完成其原K分片；atomic0完整K4096顺序、KV RMS/RoPE和cache写入不变。
不修改QR或精度版，不将固定规约重新换回atomic。

先CPU完整编译；再补8K/B16（M32）、8K/B40（M64加分组和尾块）、8K/B4（24行padding）。
前两档保留20次本体图计时，B4只做状态/图重放，不增加无关性能样本。
M64新增分支另外采核内；此前长档M32证据保留，不重新把全矩阵跑一遍来验证局部重构。
阶段出口仍须统一源码七档，模型与单卡/DFX的范围不能混用。

完整CPU lowering/PTOAS/CCE/链接已通过，constexpr生成M32/M64两个KV核内特化，共用原ABI。
`task_20260928_062238_6953107838`已提交单卡，源码冻结；[命令](run_layer.sh)、[补丁](candidate.patch)。
只补M64分支的四窗口核内（双方各四次），M32此前的长短核内证据继续保留。
