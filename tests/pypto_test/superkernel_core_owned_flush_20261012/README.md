# 过程107：本核控制行延后写回，固定短链改善9.56μs

2026-10-12。在过程100的本核初始化之上，检查控制行写回的所有权。
AICPU仅在原padding所在的独立缓存行发布两项不可变描述；每次领取由同一物理AICore初始化控制行。
本轮不改算术、派发、选核、ACK流程、early-resolve及后到通知。

原候选100仍在Wait和每次尾部排空时写回控制行。此候选对无trace路径省略这些逐任务写回，
保留完整流水等待，并在两个EXIT分支发布EXITED之前将本核两个槽位的控制行全部clean。
不省略旧协议local_predecessor_pending所在热缓存行的写回；trace诊断仍逐任务发布。
只有在整轮中执行过非普通任务时才做退出清理，普通路径不读取或清理控制行。

审查依据：scheduler_dispatch的可变控制字段写入已由过程100全部移到本核；
scheduler冷启动/退出不memset DispatchPayload，CPU功能路径不读控制行；stall诊断可能读取它。
未插桩的stall日志在EXIT之前可能看到旧控制值，这是此私有候选的诊断限制；不能据此误判故障状态。
若其他调用者以后向该控制行写入，必须重新审查cache所有权，不能直接推广此优化。

隔离构建和19项CPU派发/槽位转换检查通过，Python静态检查通过。
任务`task_20261012_162012_248941910932`在卡8退出0，五组数值/换输入/保护区及三项AIC/AIV/MIX通过。
测试为旧SDK→缓存097→候选→缓存097→旧SDK，固定17×48链，并复查局部AIC/AIV/MIX。
活动Simpler源码/绑定仍3d0b9c820，未修改共享安装。
