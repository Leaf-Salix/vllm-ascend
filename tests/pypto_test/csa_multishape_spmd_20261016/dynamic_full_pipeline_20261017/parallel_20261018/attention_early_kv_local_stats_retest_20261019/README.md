## 本轮放弃的初始线索

曾核对把INT8 L1范围分析扩展到Attention BF16三槽是否足以解除伪依赖。
正常五块都有效的稳态中，tick t末尾PV读取(t-2)%3；下一tick的KV写
(t+1)%3，二者相等，故该紧邻MTE1→MTE2边确实保护同槽。已有独立
L1三槽试验也无稳定收益。此处只是排除对正常流水该边的误判，未修改
编译器，不推断任意无效mask分布都没有保守依赖。
