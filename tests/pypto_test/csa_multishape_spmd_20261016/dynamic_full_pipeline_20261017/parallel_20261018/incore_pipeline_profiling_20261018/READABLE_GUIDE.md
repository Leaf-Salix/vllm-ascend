# CSA全72核流水：阅读版

先解压并打开`index.html`，无需启动服务或联网。页面可以选择核组、AIC/AIV
角色、总览/逐pipe模式，输入时间范围或滚轮缩放。所有核共用原始时间轴。
总览中的三条细带分别表示计算、读入和写出，按实际指令区间并集绘制。
没有画出计算/搬运的地方可能仍在执行Scalar或同步，不能直接认定为空闲。

查看指令与已有同步箭头时，将`groups/CSA_Gxx_AIC_AIV0_AIV1.trace.json`
导入Perfetto或Chrome tracing；每个文件含同一核组的1个AIC和2个AIV。
24个文件合计覆盖全部72核，没有抽样，也没有分别归零时间。

轻量图保留每条指令的名称、PC、起止时间、流水以及已经重建的同步箭头。
只省略重复的长源码栈和寄存器参数，PC对应源码见`pc_sources.json`；原始大图
及完整清理图仍保存在上一级目录。原清理器未能重建的2460条展示连线没有
在这里伪造；普通GM notify/wait也没有自动变成跨核箭头。

单核文件位于服务器同一阅读目录的`cores/`；每核均提供。下载ZIP只包含
总览和24份核组图，避免将相同事件再以单核形式重复装入。

这是128K/B16/S6的有界退避模拟诊断副本，不能当成正式实现的真机时延。
本次只整理既有采集数据，没有重新测试，也没有改变任何指令时间/时长。
“没有改变时间”指阅读版保留已有诊断trace的时间，不代表诊断副本与正式版
时序相同。退避差异还会影响访存竞争、阶段起点及计算/搬运重叠，不能只
剔除等待区间后就把其余区间当成正式版的定量性能。
