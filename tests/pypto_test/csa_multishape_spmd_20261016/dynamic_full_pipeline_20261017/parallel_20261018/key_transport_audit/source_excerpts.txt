203: ## A3 FFTS Scheduler and Logical Cluster Setup
204: 
205: ### Current TPUSH/TPOP Implementation on A3
206: 
207: The A3 TPUSH/TPOP implementation relies on **FFTS cross-core synchronization** features. During mixed kernel kickstart, the FFTS hardware establishes a logical cluster through the block scheduler.
208: 
209: ### Logical-to-Physical Core Mapping
210: 
211: The FFTS hardware builds the logical-to-physical core mapping at task launch time:
212: 
213: 1. **Block ID → Physical Cube Core**: The block scheduler assigns a physical AIC core to each logical block.
214: 
215: 2. **Subblock ID → Physical Vector Core**: Each subblock (0, 1) maps to a physical AIV core that becomes a buddy of the assigned Cube.
216: 
217: 3. **Intra-cluster sync resolution**: The FFTS hardware resolves all intra-cluster synchronization and communication paths based on this mapping.
