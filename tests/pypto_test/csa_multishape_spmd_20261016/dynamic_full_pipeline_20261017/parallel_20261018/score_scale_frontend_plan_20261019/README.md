# 将连续页证明前移到现有 META 阶段

## 动机和范围

上一轮每叶两条 AIV 重复证明连续页，128K/B16 全 L1 小幅回退。
这次只复用已验证的连续搬运/逆序还原，改由现有唯一 metadata planner
检查每请求整个有效压缩历史的页表；所有叶和两条 AIV 共用结果。
旧负例不是永久禁用依据，但本次理论收益仍须真机验证。

当前为待编译、待设备验证候选，不代表默认采用或性能达标。
三方同进程比较采用原分 task PTO、已验证动态 SPMD、候选动态 SPMD；
相同正式权重、输入和冻结 PTOAS，不叠加新的编译器优化。

## 布局、同步和回退

沿用 group_offsets 的所有原分区，在尾部追加 2*B 个 INT32，
每请求两项为 first_page/direction。方向为 -1/0/+1；0 表示退回逐页读取。
唯一 planner 每轮覆盖所有请求项；既有 PHASE_META 完成缓存发布/获取。
无新 Tensor 根、Host 数值回读、task、阶段或等待协议。
整体请求证明比逐叶证明更保守，碎片或混合方向页表完整走原路径。

## 待验证

- 不提供样例形状的完整动态 CPU 编译和工作区布局检查。
- 原输入 128K/B16、B28 同轮精确门槛及五窗口完整 L1。
- 需要时补规范 Native 构造的碎片页、metadata 与 padding 图回放。
- 原始失败、候选及结果完整保留；不能把 CPU 或模拟时间当作真机收益。
