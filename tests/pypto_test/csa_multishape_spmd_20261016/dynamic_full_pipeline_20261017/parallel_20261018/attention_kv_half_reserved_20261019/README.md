# 128K Attention：32行独立KV缓冲与UB索引

本候选针对E43在128K/B16观察到的AIC等KV累计中位101.61μs供数等待。
该数值包含AIV前拍工作，只用于定位，不能作为可直接省去的DMA时间。
E44两遍显式64行DMA仍回退2.33%；E45保持独立64KiB KV缓冲则超出真实UB容量。
本版选择32KiB持久KV缓冲，每个lane分两段32行写入原64行GM槽，期望减少
KV与softmax/PV临时Tile同址复用造成的串行。真实容量上限保持188416B。

所有动态轴、QK/PV、softmax归约、在线归并、最终发布数学保持。物理索引先
整段载入UB，再由Scalar读取；合法行DMA与无效行置零分两遍。每个输出行
完整写入，负值及上界均检查，没有使用undefined OOB。原始SWA/逻辑回退
仍走原64行路径，两段都写完后才执行原KV_READY；三槽与事件计数不改变。

实现从正式ops源码编写后冻结为source_candidate，正式37份源码恢复为已采用版。
prepare_candidate.py记录可复现构造方法，并逐字确认开始时正式源与参考一致，
防止覆盖其它会话的修改。首次准备脚本少了中文注释前缀，AST阶段失败，
尚未写入ops或提交设备；修正后完成。未修改组件源码或共享安装。
