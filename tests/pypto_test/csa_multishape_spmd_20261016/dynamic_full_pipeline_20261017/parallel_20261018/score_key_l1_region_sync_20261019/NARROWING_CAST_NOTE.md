# 常量cast的保守穿透条件

检查getConstIndexValue时补充了缩窄cast控制。完整PTOAS流水中的旧v2
已经正确处理这两个控制：cast先折叠，缩窄地址例子的RAW有等待，后续
写另槽本就不需要WAR；缩窄offset例子真实重叠，WAR一直存在。
没有把这两例报告成已复现的新生成错误。

新增宽度/符号检查只让helper在数值可证明不变时穿透cast；不能证明就
返回unknown，防止将来依赖分析调用顺序变化时把256->i8的0当成256。
地址例子之前的WAR期望已纠正，RAW检查保持；offset例子的WAR保持。
该加强作为防御性范围证明约束，与已复现的动态基址#1620不同。

v3二进制独立生成；运行中的v2未覆盖。要复用v2的七档设备证据，须将
每档原始PTO分别用v3重生成并确认完整C++逐行一致，不能只用源码相似
或汇总计数相同代替。若任何一档改变，则不能把v2结果直接用于该档v3。
