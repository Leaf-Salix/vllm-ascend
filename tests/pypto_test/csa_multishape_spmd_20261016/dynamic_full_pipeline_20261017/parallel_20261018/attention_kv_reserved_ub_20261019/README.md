# 显式行DMA的独立KV UB缓冲候选

E44完整CPU中KV64KiB与softmax临时、probability及PV载入都从UB65536开始。
即使去掉MGATHER内部同步，实际存储复用仍会让MTE3/Vector彼此等待。本版在
Attention循环外创建64KiB目标，供同一显式行DMA helper重复写入；每轮每行
仍完整覆盖，不读旧内容，不复制整块Tile，不新增GM或核间协议。

这只是资源表达候选：必须确认内存规划真的把它与softmax/PV临时量分开，
且未超出真实UB容量；未满足前不提交设备性能。关闭物理plan时无消费者，
后续也须确认未用buffer被消除。没有固定B/S/history或改变矩阵、softmax、
在线归并/最终发布数学。ops编写后冻结，正式版本已恢复，依赖仓库未修改。

CPU v1长/短分别要求202240/201472字节Vec，超过当前平台可用188416字节，
均未通过AllocateMemoryAddr，未提交设备。没有扩大上限或删减计算强行通过。
这是本候选的资源代价，不作为组件bug提交。后续应先减少真实活跃临时空间
或采用更小的流水缓冲，不把声明独立buffer当成自动可行；当前暂不继续此版。
