## 最终执行结构与边界

- 一个动态JIT入口，所有算法写在同一文件，只依赖 `pypto.language`；没有从CSA/HCA/pypto-lib运行时复用函数。
- 六分支：T≤32、33～48、49～95、精确96、97～144、T>144。B/S仍由T=B×S决定分派。
- 第一阶段用一个SPMD覆盖可用核组，双AIV供数给Cube，分别产生投影及RMS部分和；保留完整阶段屏障。
- 第二阶段按逻辑AIV分工：中大档24核Sinkhorn、24核混合，小档按token对再切D；14档设备探针确认48核均有有效工作，各输出恰好覆盖一次。
- BF16输入及mixed输出、FP32 HC权重与post/comb、完整20轮Sinkhorn、epsilon和冻结精度门禁均保留。
- 没有修改PyPTO、Simpler、PTOAS、PTO-ISA、pypto-lib，没有修改整模型forward。
