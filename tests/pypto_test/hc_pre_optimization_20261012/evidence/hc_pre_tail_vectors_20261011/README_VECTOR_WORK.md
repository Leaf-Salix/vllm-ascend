## 证据与边界

- `probe_full_device_counts/*_tail_work.json`：逐核真实工作表。编号是 SPMD 逻辑 AIV，不冒充物理核号。
- `vector_work_summary.csv` 和 `vector_work_summary.json`：逐档汇总及每张真实 L1 泳道路径。
- 未插桩正式计算：`pto_only_full_vectors_14/`；旧 PTO 对照：`pto_only_baseline_14/`。
- 参与48核不等于全程100%占用，也不自动代表性能提升。未插桩 L1 中部分小档及大档耗时回退；汇总保留全部数据，后续仍需优化第二阶段的工作量均衡及填充计算。
- 当前 CCE 对 read_clock/physical_core_id 的内联汇编报类型错误；没有修改任何依赖。最终探针只保留 Vec tile 写回的真实计数，不生成假的第二阶段时间片。L1仍是完整 incore task 的真实泳道。
- 任务：旧 PTO `task_20261011_150247_16263909747`；新版 `task_20261011_151131_204128028631`；新旧逐核探针 `task_20261011_151817_236143227908`。
