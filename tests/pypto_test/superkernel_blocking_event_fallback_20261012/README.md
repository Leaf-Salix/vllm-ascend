# 过程072：事件不足时保留即时交接，尾回调安全回退

2026-10-12。私有功能修复保留：显式同步使通知事件全部可能占用，或动态 ID 范围无法证明时，
不再因此拒绝整个 task。原有首次探测发现同核后继时仍可立即交接；只有该探测失败后调用的尾回调，
改用 `PIPE_ALL` 等待，不再借用任何通知事件或提交通知 DMA。

这不是所有后到窗口都已支持：阻塞等待期间不能继续监测派发寄存器，等待返回后的交接也没有旧计算可重叠。
保留这个限制，不能把该路径的交接数量算成计算重叠或性能收益。
资源充足的函数保留原通知回调，原调度、ACK、核选择、`allow_early_resolve`、MIX完成语义均未修改。
用户确认的局部 Wait 手工标识和 chip swimlane/PMU/参数 dump 回退继续保留。

## 实现

- PTOAS `9ddc2e25`：显式事件集合无法留出通知槽位时生成逐函数 blocking-poll 合同；
  作者的 Set/Wait 及 ID 不变。未知范围只表示编译器不能分配额外事件，调用方仍必须提供合法硬件 ID。
- PyPTO `fd4686875`：只替换对应函数的内部尾回调为 `pipe_barrier(PIPE_ALL)`；
  原入口 tag、Set、Wait、metadata 和即时交接路径不变，没有增加作者需要写的属性。
- 新握手宏阻止旧包装器误用 EVENT_ID7；重复、非法、相互冲突或没有对应回调的合同明确报错。
- 私有 vLLM 诊断 `41fce0a4`：分别统计阻塞完成后的交接，避免把无通知交接判错或算作计算重叠。
- PyPTO诊断 `cbaf0e88f`：仅在小用例的独立构建里记录阻塞回调实际执行，默认后端没有该记录开销。
  Simpler仍为`6174ec5db`，PTO-ISA仍为`327cd5869`，没有运行时或ISA修改。

## 验证

12项后端单测通过；6项FileCheck涵盖事件耗尽、未知动态范围、原有事件分配、有限动态范围、
Scalar控制流的Wait同步边界以及不安全前缀拒绝。最初Ruff报告分支数超限，删除冗余快速返回后通过，未豁免规则。
实际AIC/AIV包装器检查确认：新回调只有`PIPE_ALL`，没有事件、通知复制或数据缓存操作；
后续短计算的独立诊断构建额外写一个trace标记，仅用于证明执行路径。

两次单卡任务均使用CANN9.2/TMR，卡0、退出0并释放设备，均未采性能样本：

| 用例 | 任务 | 结果 |
| --- | --- | --- |
| work=64，原单次探测/新回退，各换输入两轮 | `task_20261012_022435_108297320198` | 新路径两轮AIV 48/48、AIC 24/24即时交接；全部输出、保护区及图重放通过 |
| work=1，带回调执行标记，各换输入两轮 | `task_20261012_022709_117784020308` | 实际命中阻塞回调，通知DMA为0；全部输出、保护区及图重放通过 |

短计算每轮开始前清空trace，计数如下：

| 核型/轮次 | 即时交接 | 阻塞回调执行 | 阻塞完成后交接 | 通知DMA |
| --- | ---: | ---: | ---: | ---: |
| AIV/输入0 | 7 | 41 | 6 | 0 |
| AIV/输入1 | 4 | 44 | 8 | 0 |
| AIC/输入0 | 7 | 17 | 10 | 0 |
| AIC/输入1 | 0 | 24 | 13 | 0 |

每轮即时交接数与阻塞回调数之和分别为48个AIV或24个AIC成员。
这里“即时交接”是总交接减去回调返回后交接，不能单凭这个计数确认原计算重叠时长。
图重放之间没有清空回调诊断标记，因此重放中的`blocking_callbacks`是自上次Host reset以来的累计标记，
不能当作每次重放的调用数；重放仅用于输出/边界验证。

未重跑CSA、七档、Native或整模型；本轮是功能覆盖扩展，不声明性能改善。
最新CSA计时仍是[过程071四路对照](../superkernel_score_scalar_plan_20261012/README.md)。
一般只读GM前缀的写者/别名证明仍未实现，事件不足时阻塞期间的后到窗口也未解决。

## 证据与复现

`source/`保存测试及合同头文件，三个仓的增量补丁保存完整修改，零上下文补丁用`git apply --unidiff-zero`。
`compiler/`保存12项UT、构建日志、6项FileCheck结果、生成代码节选及包装器检查。
`long_work/`和`short_work_observed/`保存完整输出、逐核trace及重放验证；`functional_summary.json`提供计数摘要。

`repro/`脚本需放回已有私有环境的`artifacts/`，依赖该环境和原小用例驱动，不是新clone独立发行包。
长计算产物由`fd4686875`生成；带标记的短计算产物对应`cbaf0e88f`的probe。
使用当前probe重新编译时，exhausted模式均带诊断标记，不能当作未插桩性能产物。
短计算编译命令（在私有PyPTO中source私有env后）：

```bash
python tests/st/runtime/scheduling/task_boundary_allocated_event_probe.py \
  --event-id exhausted --compile --compiled ../artifacts/blocking_event_observed_compiled_20261012
```

设备验证经`task-submit --device auto --device-num 1`提交对应repro脚本，禁止直接抢占设备。
