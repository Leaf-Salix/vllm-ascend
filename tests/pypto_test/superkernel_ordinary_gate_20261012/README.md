## 修改和假设

在过程090双缓冲干净状态复用的基础上，利用已有LocalContext热缓存行的字段传入普通入口证明。
AICore仅对被证明不会访问交接状态的入口跳过前驱、trace、tail及prefix能力读取；
交接函数也明确拒绝把普通入口当作可提前启动的后继。
带标记、legacy、不明入口和矛盾合同仍走完整处理，不改变原派发、ACK、选核或early-resolve。
证明仍是已知测试入口的编译钩子，尚未形成通用编译器识别，不能当作生产功能完成。

私有Simpler基于`3d0b9c820`，PyPTO `94c37915f`，PTOAS `fdebb38b`，CANN9.2。
独立构建后恢复Simpler源码，现有安装没有切换。
CPU检查初次因测试副本与原目录的头文件混用而重定义，改为完整复制runtime头文件后19项通过。
这是测试构建准备错误，不是设备功能失败；首次日志仍保留。
