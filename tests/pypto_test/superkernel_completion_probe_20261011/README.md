# A3有序DMA完成通知：功能与开销小用例

2026-10-11，实施过程056。任务`task_20261011_192846_151447026363`在单卡0退出0，设备已释放。
此过程验证完成标志可由Scalar轮询，尚未验证后到task新增交接。未改变Simpler/PTOAS、
生产编译器或CSA默认；私有PyPTO仅提交测试驱动`17377846a`，SDK保持过程055版本。

## 方案与范围

在测试进程生成wrapper时替换局部Set适配器，不把测试代码要求变成算子接口。
各图只有一个SPMD任务：24个AIC或48个AIV，每核一个block，没有后继。
小用例专用scratch为L1末尾64B（524224）或UB末尾64B（196544），
实际生成的小矩阵/向量buffer未占用这些地址。不能直接把这两个常量推广到任意CSA任务；
正式实现必须由编译器证明空闲或预留空间，并处理同步事件占用。

AIC把MTE2/MTE1/M/FIX接到MTE3，AIV把MTE2/V接到MTE3，再以DMA写出64B完成通知。
标志、通知源、时序分别占用独立cache line；每次重放重新清零和写回，避免读取上次完成标志。
三路为普通PIPE_ALL、通知后PIPE_ALL、通知后轮询标志与既有DATA_MAIN_BASE寄存器。
三路共同保留诊断读钟、一个输出word采样及末尾完整PIPE_ALL；runtime完成流程不变。
没有新增AICPU派发、ACK处理或early_resolve行为，也没有读写SPR的MMIO地址。

## 功能证据

两种计算长度（loops=1/64）、AIC/AIV、三路、各两组输入均完成。
轮询路径每次均因读到DMA完成标志退出，没有超时，也没有意外后继。
轮询标志之后、显式末尾PIPE_ALL之前采样的输出word正确；最终全部输出逐bit正确，
输出和trace保护区通过，随后图重放完成。此为本探针的数据可见性证据，
不代替所有操作类型的完整流水合同证明，也不等于后到任务已经交接成功。

[results.json](results.json)保存全部检查结果和180次计时样本，24份`trace_*.json`
保存两组输入在断言之前抓取的逐核原始记录。原始clock tick仅作诊断，不在此换算核内成本；
最终性能用NPU Event测单次完整图重放，包含运行时与调度开销。

## 驱动修正与失败记录

CPU首次把Acc/Vec局部变量混用，修正为不同变量；第二次探针错误假设IR参数本身按
Tensor优先排序，包装断言失败，改为依照实际ABI筛选Tensor参数。
CPU生成代码审查发现参数槽存的是Tensor描述符，修正为buffer.addr和start_offset后
重编译六个变体。修正之前的产物没有上设备。编译日志保留了各轮过程。

前三次队列提交都在计算前退出：任务`task_20261011_192755_148069018892`
因外部ATB环境脚本的未定义ZSH_VERSION与set -u冲突；一次错误的帮助探测命令被
队列当作任务提交，`task_20261011_192812_149102026842`因不存在的脚本exit127；
任务`task_20261011_192819_1495921622`因从非Git目录加载资源限制脚本exit128。
随后启动脚本先进入私有PyPTO仓，再加载环境，完成正式任务。这些是驱动错误，不是设备算子故障。

## 复现与边界

随目录保存驱动、两个生成的poll入口、编译日志、队列日志及版本。
先在私有PyPTO仓source私有env，CPU执行驱动的`--compile --compiled <目录>`，
再经task-submit执行启动脚本。启动脚本必须使用队列的TASK_DEVICE，并将设备日志定向到独立目录。
脚本中路径是此次私有环境的复现记录，不写入产品接口。

继续保留用户确认的显式wait_pre_task_end与诊断模式回退；不做自动识别。
本轮没有CSA新测量，未插桩128K/B16仍以过程054为准。
