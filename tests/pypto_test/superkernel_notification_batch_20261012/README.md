# 过程101：合并通知区发布屏障，AIC功能失败，暂不保留

2026-10-12。过程097在每次调用时逐核初始化192B通知区，每核调用cache_flush_range，
每次都执行dc cvac以及dsb sy、isb。普通入口也承担这项冷启动成本。
本候选保留所有通知字的初始化、每条cache line的clean和完整后到通知，
收集当前调度线程拥有的通知地址，在开始派发前执行一次批量clean加完成屏障。
串行初始化路径同样只合并屏障，不扩大刷新范围、不触碰其他线程拥有的行。

新增公共平台内部cache_flush_ranges辅助函数；现有cache_flush_range和其他调用者不变。
A2/A3 TMR只调整assign_own_clusters与post_handshake_init的初始化，
所有运行时派发、ACK、选核、Wait/Set及原调用工作量保持。
隔离SDK编译通过。20项CPU检查通过，新增检查确认两条初始化路径只发布已初始化的自有范围，
通知每个字的内容、范围唯一性和对齐均正确；CPU结果不代替设备DMA可见性验证。

任务 `task_20261012_132100_225793121124` 在卡1退出1。五轮固定链的输出、保护区、换输入检查均通过，
随后局部AIC检查报507018，AIV与MIX通过；不能把本候选计为完整功能通过。
同卡旧→缓存→批量屏障→缓存→旧，仍测固定1/17级和5/50μs及输出/保护区；
随后AIC/AIV/MIX三项设备功能检查。没有改变计时方式或追加CSA、16卡测试。
