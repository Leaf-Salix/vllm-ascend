## 优化与测量口径

| 配置 | Native | BSH / TND |
| --- | --- | --- |
| 编译入口 | named npugraph_ex、fullgraph=True | 生产opaque dsv4_csa_forward，经同一named backend |
| dynamic / inplace / force_eager | False / True / False | False / True / False |
| static kernel | 开；必须实际编译、装包成功 | 配置开；整个半层已由PyPTO替换，不要求产生Native静态包 |
| SuperKernel | 开；必须实际硬件融合事件 | 关，继承参考PTO整体程序口径，PyPTO自行编排 |
| 图重放 | 后端唯一图直接replay，无外层嵌套图 | 同左，必须实际进入PTO服务，拒绝Native回退 |
| 确定性 | level1、HCCL_DETERMINISTIC=true | 同左；PTO atomic_add=0 |
| profiler | 独立计时后采集 | 同左，不将profile时间填入性能表 |

这是三种执行实现及其优化配置的部署口径对比，不是只改CSA内部一个kernel的单因素实验。
Native已有多流重叠保持开启。后端graph owner、底层graph和三份cache分配必须互相独立。

每case同进程同卡；六种执行排列各重复4次，共24轮、每arm每轮100次，报告轮平均延迟。
另采每arm120个恢复初态后的单次replay，报告min/mean/max/P50/P95；两个P95不得混用。
保留所有样本，不剔除尾部样本，不拿图片或旧环境结果填表。

附加变长：B4长度[6,3,1,1]、T11；B16长度

## 精度与结构门禁

- 比较输出、TopK、SWA、compressed、state、Indexer key/scale和Indexer state。
- 全张量bytewise检查之外，浮点cache误差只统计Native slot实际可写区域，排除未写历史稀释。
- BF16、FP16、FP32分别按原始位模式统计ULP，保留P50/P95/P99/max、差异元素数、max_abs及relative L2。
- TopK报告排列/集合差异及替换索引数量；越界、重复或少选停止性能采集。
- 有效浮点写区出现NaN/Inf、metadata改写或slot外写入停止测试。
- 每arm compiled callable与直接replay、连续两次replay、连续100次后及恢复初态后必须逐位一致。
- S6 TND对BSH八类状态逐位一致后才收性能；两种PTO对Native差异如实测量，不冒充逐位验收。

### 本轮结论

单次恢复与连续重放是不同状态/排队口径，结论不得混用。连续100次的8K/B16中，
TND平均730.97μs、Native741.91μs，TND反而快约1.48%；以下概括明确以单次均值为准。

- 按恢复初态后的单次均值：128K六档TND比优化后的Native快1.07%～14.21%；8K三档慢1.09%～2.25%。
- 同一单次口径下，TND比BSH慢0.51%～1.64%；九档八类完整输出/state与BSH逐位一致，未增加S6数值差异。
- 两种PTO对Native的输出relative L2均为0.3328%～0.4211%；ULP P95为5～7，P99为26～35，max最高30858。
- TopK结构全部合法，但相对Native，大多数行的选择集合不同；有效cache/state也有数值差异。
  不能宣称Native逐位对齐，也不能称所有元素误差已限制在几个bit或100ULP内。
- 真正变长T11：TND慢9.54%；T60：TND快2.06%；BSH拒绝这两类请求。
- 上述为单层合成输入/历史对比，不代替整模型DP/EP16、EPLB、真实prompt或DSpark接收率验收。
  接收步长3.8是给定参考，未作为本轮实测结果。

增量文档检查和5项ULP工具CPU测试通过。完整仓库format CI此前有历史归档文件错误，
本轮未以修改归档/原始日志的方式消除，不宣称完整CI通过。没有修改CSA kernel或重装框架。
